Dành cho người mới làm game Unity trên Acer Nitro AN515-43 (RAM 16GB)

Trang tải & chia sẻ game Unity cá nhân gọn nhẹ

Đây là nơi bạn giới thiệu các tựa game tự làm trên Unity, gắn link tải bản PC (.zip) và Android (.apk), rồi gửi link cho bạn bè mở trực tiếp trên Google Chrome hoặc Cốc Cốc để tải về chơi.

Hướng dẫn nhanh trên Chrome & Cốc Cốc

Áp dụng cho cả bạn bè tải game về chơi và bạn kiểm tra link:

  1. 1 Mở đường link trang web trên Google Chrome hoặc Cốc Cốc, tìm game và chọn Tải PC (.zip) hoặc Tải Android (.apk).
  2. 2 Với bản PC (.zip): tải xong hãy giải nén ra thư mục riêng rồi mới chạy file .exe.
  3. 3 Với bản Android (.apk): mở file tải về và bật quyền Cho phép từ nguồn này nếu máy hỏi để cài đặt.

Cẩm nang tự vận hành

Hướng dẫn từ A đến Z cho người mới

Làm theo từng bước dưới đây để tự giữ mã nguồn, đăng game build từ Unity lên mạng và chia sẻ cho bạn bè một cách chủ động.

Bước 1 • Giữ file index.html trên máy

Lưu và quản lý file index.html ở thư mục riêng

Tạo thư mục như D:\GameWeb trên chiếc Acer Nitro AN515-43 của bạn và đặt tên file chính là index.html. Mỗi khi cập nhật thông tin hoặc link game, hãy bấm Tải về file index.html mới rồi thay vào thư mục này để luôn giữ bản mã nguồn mới nhất.

Bước 2 • Build game trên Unity 6.3 LTS

Xuất bản game từ Unity cho PC và Android

Trong Unity 6.3 LTS, mở cửa sổ build, chọn Windows (nén thư mục xuất ra thành file .zip) hoặc Android (xuất file .apk). Với cấu hình RAM 16GB trên máy bạn, hãy ưu tiên test kỹ cảnh 2D hoặc 3D nhẹ trước khi xuất bản.

Bước 3 • Đưa file game & web lên mạng

Tải file game lên nơi lưu trữ rồi gắn link vào web

File .html không chứa trực tiếp file game nặng hàng trăm MB. Hãy tải file .zip / .apk lên Google Drive, GitHub Releases, itch.io hoặc hosting riêng để lấy link tải, dán vào phần Quản lý & Xuất file HTML, xuất file index.html mới rồi tải lên hosting web của bạn.

Bước 4 • Chia sẻ & khai báo Google

Gửi link cho bạn bè & khai báo Google Search Console

Gửi link trang web cho bạn bè mở trực tiếp trên Google Chrome hoặc Cốc Cốc để tải game. Nếu muốn người khác tìm thấy trang trên Google, hãy thêm địa chỉ web vào Google Search Console và gửi yêu cầu lập chỉ mục (indexing), sau đó chờ Google quét dần theo thời gian.
